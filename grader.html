MTH 160 Instructor Grader

Everything runs in your browser. Student files are read on this computer and are not uploaded anywhere. The grading seed and integrity settings are typed in here and are never stored.

Key: how to use this page and read the results

Workflow

  1. Choose the Canvas submissions .zip (or the .xlsx files), enter your private grading seed, and open Integrity settings to type the template marker and trap word.
  2. Click Run grading. Tick "Show only files that need review" to see just the flagged rows (red bar on the left). Green bar means nothing to look at.
  3. Click any row to open its details: the code the student pasted and every failed check with the values that were tested.
  4. Click Download CSV to keep the full results. Enter the automated score in Canvas and add the hand-graded parts (instructions quality, reflection, scratchwork).

Columns

Auto scorePoints earned by the automated checks, as "earned / possible". Extra credit is shown as "+ 2 EC". A category earns its points only if every check in it passes.
Categories without pointsWhich categories lost points. Click the row for the exact failed checks.
CodeWhether the submission code matches the file (see below). The word in parentheses says where the code was found: file (pasted in the spreadsheet) or quiz (quiz export).
IntegrityThe template marker result and any trap-word hits. These are weak signals for triage.

Categories that can lose points

Template and layoutFile name is not First_Last.xlsx, the template version is not current, or a required tab is missing.
Only allowed operationsA function other than IF, AND, OR, LN or EXP was used (the template's own SUM cells are allowed).
Instructions on every tabA tab has no written instructions in A1:D2. This checks that text exists, not whether it is good.
Required test valuesThe published test values are not typed in the input cells.
Each calculator, tax, APYA randomized test failed, or an answer cell holds a typed number instead of a formula. Tax also needs at least 7 IF formulas per filer in the logic area, and APY needs an IF in F1.

Code status

The grader reruns the check on the file and compares it with the code the student pasted.

OKThe code matches the file and the points it claims.
OK_GRADING_SEED_DIFFERSThe code is honest, but your seed gives different flags. Look at the file.
FILE_CHANGEDThe work was edited after the student got the code, or a different file was submitted.
CLAIM_MISMATCHThe code claims results the file does not produce.
NAME_MISMATCHThe code is valid for this content but was issued under another name. Typical of a copied file, but a renamed file does it too.
BAD_CHECKSUMThe code was mistyped or edited.
NO_CODENo code in the spreadsheet, and none in the quiz export. Ask the student for it, or grade on the automated score alone.
CODE_NO_FILEA code is in the quiz export but no matching file was found. Appears only when you load the quiz CSV.

Integrity

marker OKThe hidden template marker is intact.
marker ALTEREDA marker cell exists but holds a different value.
marker MISSINGNo marker at all, for example a file rebuilt from scratch or pasted into a new workbook.
marker n/aYou left the marker field empty.
trap word at ...Cells that contain your trap word.

Suggested review order

  1. FILE_CHANGED, CLAIM_MISMATCH, NAME_MISMATCH, BAD_CHECKSUM: open the file and compare it with what the student reported.
  2. NO_CODE: usually a student who skipped the paste step. Ask for the code or grade on the automated score.
  3. Marker MISSING or ALTERED, trap word hits: weak signals. Look at the work itself and, if you have doubts, talk with the student.
  4. Lost categories only: no review needed beyond confirming the failed checks. These are just lost points.

A flag is a reason to look at a submission, not a finding of misconduct. A re-save in another program can remove the marker, and a student can innocently reuse the trap word.
